## Project Overview

Dream Ramen (夢のラーメン) is a ramen cooking game built with React 19. Players select ingredients to create ramen recipes, earn points, and unlock new ingredients.

## Commands

This project uses Turborepo for task orchestration with intelligent caching and dependency management.

```bash
turbo dev          # Start dev server at http://localhost:3000
turbo build        # Production build (with type check)
turbo test         # Run tests (with type check)
turbo check        # Run all checks (type + lint + format)
turbo check:type   # TypeScript type check (with route generation)
turbo check:lint   # Lint with oxlint
turbo check:format # Format check with oxfmt
pnpm format        # Auto-format code with oxfmt (no turbo needed)
```

**Note**: Task dependencies are defined in `turbo.json`. For example, `turbo check:type` automatically runs `generate:routes` first.

## Architecture

### Tech Stack

- React 19 with React Compiler (babel-plugin-react-compiler)
- TanStack Router (file-based routing)
- Zustand (state management with localStorage persistence)
- Tailwind CSS v4 (via Vite plugin)
- Vitest + Testing Library

### Path Alias

`@/*` maps to `./src/*`

### Routing

File-based routing under `src/routes/`:

- `__root.tsx` - Root layout
- `index.tsx` - `/` Main screen
- `cooking.tsx` - `/cooking` Cooking screen
- `result.tsx` - `/result` Result screen
- `collection.tsx` - `/collection` Collection/encyclopedia screen

**Note**: `src/routeTree.gen.ts` is auto-generated by TanStack Router plugin. Do not edit manually.

### State Management

Zustand store in `src/stores/gameStore.ts`:

- Persisted to localStorage under key `ramenGameState`
- Actions: `unlockIngredient`, `createRamen`, `resetGame`
- Use selectors (e.g., `selectPoints`) for optimized re-renders

### Directory Structure

```
src/
├── components/    # UI components (MainScreen, CookingScreen, etc.)
├── data/          # Master data (ingredients.ts, recipes.ts)
├── lib/           # Utilities (recipeMatch.ts)
├── routes/        # TanStack Router route files
├── stores/        # Zustand stores
└── types/         # TypeScript type definitions
```

### Game Logic

- Recipe matching in `src/lib/recipeMatch.ts` - matches selected ingredients to recipes
- Ingredient slot order doesn't matter for matching
- Unmatched combinations return default "イマイチなラーメン" recipe
