# ラーメンゲーム 画面設計書

## 画面一覧（全3画面）

1. メイン画面
2. 調理画面
3. 結果画面
4. 食材図鑑画面（ラーメン図鑑 + 食材一覧の2タブ構成）

### 1. メイン画面

**目的**: ゲームのハブとなる画面  
**主な機能**:

- 現在の所持ポイント表示
- 発見したラーメン数の表示
- 各機能への遷移ボタン

**表示要素**:

```
┌─────────────────────────────┐
│   🍜 ラーメンマスター         │
├─────────────────────────────┤
│ 所持ポイント: 15pt           │
│ 発見したラーメン: 0/10        │
├─────────────────────────────┤
│                             │
│   [ラーメンを作る]           │
│                             │
│   [食材図鑑]                │
│                             │
└─────────────────────────────┘
```

**インタラクション**:

- 「ラーメンを作る」→ 調理画面へ遷移
- 「食材図鑑」→ 食材図鑑画面へ遷移

---

### 2. 調理画面

**目的**: ラーメンを作成する画面  
**主な機能**:

- 5つのスロットから食材を選択
- ラーメンの調理実行

**表示要素**:

```
┌─────────────────────────────┐
│   ラーメンを作る              │
├─────────────────────────────┤
│ スープ: [醤油スープ ▼]       │
│                             │
│ 麺    : [中太麺 ▼]          │
│                             │
│ 具材1 : [チャーシュー ▼]     │
│                             │
│ 具材2 : [ネギ ▼]            │
│                             │
│ 具材3 : [メンマ ▼]           │
│                             │
│      [調理する！]            │
│      [戻る]                 │
└─────────────────────────────┘
```

**スロット仕様**:
| スロット名 | 必須/任意 | 「なし」選択 | 初期表示 |
|----------|----------|------------|---------|
| スープ | 必須 | 不可 | 解放済み食材の1つ目 |
| 麺 | 必須 | 不可 | 解放済み食材の1つ目 |
| 具材1 | 任意 | 可能 | 「なし」 |
| 具材2 | 任意 | 可能 | 「なし」 |
| 具材3 | 任意 | 可能 | 「なし」 |

**ドロップダウン内容**:

- 解放済みの食材のみ表示
- カテゴリに対応した食材のみ表示
  - スープ → category: "soup"
  - 麺 → category: "noodle"
  - 具材1-3 → category: "ingredient"

**インタラクション**:

- 「調理する！」→ 結果画面へ遷移（レシピ判定を実行）
- 「戻る」→ メイン画面へ遷移

---

### 3. 結果画面

**目的**: 調理結果を表示する画面  
**主な機能**:

- 完成したラーメン名の表示
- 評価とポイントの表示
- 図鑑登録通知（初回のみ）

**表示要素**:

```
┌─────────────────────────────┐
│       🍜                     │
│   醤油ラーメン！              │
│                             │
│   ★★★★☆                   │
│                             │
│   獲得ポイント: +20pt        │
│                             │
│  「王道の美味しさ！」         │
│                             │
│  ✨ 図鑑に登録されました！    │
│   （初回のみ表示）            │
│                             │
│   [もう一度作る]             │
│   [メインに戻る]             │
└─────────────────────────────┘
```

**表示パターン**:

#### パターンA: 新規発見（初回作成）

- ラーメン名を表示
- 評価（星1-5）を表示
- 獲得ポイントを表示（緑文字で強調）
- コメントを表示
- 「✨ 図鑑に登録されました！」を表示

#### パターンB: 既知レシピ（2回目以降）

- ラーメン名を表示
- 評価（星1-5）を表示
- 獲得ポイントを表示
- コメントを表示
- 図鑑登録通知は非表示

**インタラクション**:

- 「もう一度作る」→ 調理画面へ遷移（スロット選択は維持）
- 「メインに戻る」→ メイン画面へ遷移

**データ更新**:

- 所持ポイントに獲得ポイントを加算
- 初回の場合、図鑑に追加
- 作成回数をカウント

**主な機能**:

- タブ切り替え（ラーメン図鑑 / 食材一覧）
- 発見済みラーメンの一覧表示
- 食材の解放

│                             │
│ === 麺 ===                  │
│ ✓ 中太麺                    │
│ ✓ 細麺                      │
│ 🔒 太麺 [10pt] [解放]       │
│ 🔒 ちぢれ麺 [10pt] [解放]   │
│                             │
│ === 具材 ===                │
│ ✓ チャーシュー              │
│ ✓ ネギ                      │
│ ✓ メンマ                    │
│ ✓ のり                      │

│ ...                         │
│                             │

**表示要素（ラーメン図鑑タブ）**:

```
┌─────────────────────────────┐
│   食材図鑑                   │
│   所持ポイント: 35pt         │
├─────────────────────────────┤
│ [ラーメン図鑑] [食材一覧]    │
├─────────────────────────────┤
│ 発見: 3/10                   │
│                             │
│ 1. 醤油ラーメン              │
│    ★★★★☆ / 20pt          │
│    作成回数: 2回             │
│                             │
│ 2. 塩ラーメン                │
│    ★★★★☆ / 20pt          │
│    作成回数: 1回             │
│                             │
│ 3. 味噌ラーメン              │
│    ★★★★☆ / 25pt          │
│    作成回数: 1回             │
│                             │
│ 4. 🔒 未発見                │
│                             │
│ 5. 🔒 未発見                │
│                             │
│ ...                         │
│                             │
│   [戻る]                    │
└─────────────────────────────┘
```

**タブ切り替え仕様**:

- タブクリックで表示内容を切り替え
- 選択中のタブは強調表示
- 所持ポイントは常に表示

**食材一覧タブの表示ルール**:

**解放済み食材**:

- ✓ アイコン + 食材名
- 解放ボタンなし

**未解放食材**:

- 🔒 アイコン + 食材名 + [コストpt] + [解放]ボタン
- ポイント不足時は[解放]ボタンをグレーアウト

**カテゴリ順**:

1. スープ
2. 麺
3. 具材

**ラーメン図鑑タブの表示ルール**:

**発見済みレシピ**:

- レシピ番号 + レシピ名
- 評価（星）+ 獲得ポイント
- 作成回数

**未発見レシピ**:

- レシピ番号 + 🔒 未発見

**インタラクション**:

- タブクリック → タブ切り替え
- [解放]ボタンクリック（食材一覧タブ）→ 確認ダイアログ表示
  - 「○○を△ptで解放しますか？」
  - [はい] / [いいえ]
- [はい]選択時:
  - ポイントを消費
  - 食材を解放
  - 一覧を更新（✓表示に変更）
- [戻る]ボタン → メイン画面へ遷移

**データ更新**:

- 食材解放時:
  - 所持ポイントからコストを減算
  - 解放済み食材リストに追加
  - LocalStorageに保存

## 画面別の状態管理

### メイン画面

**表示に必要なデータ**:

- `points`: 所持ポイント
- `discoveredRecipes.length`: 発見したレシピ数
- 総レシピ数（定数: 10）

**データ取得タイミング**:

- 画面表示時に毎回取得

---

### 調理画面

**表示に必要なデータ**:

- `unlockedIngredients`: 解放済み食材リスト
- 全食材データ（カテゴリ別フィルタリング用）

**状態保持**:

- 各スロットの選択状態（ドロップダウンの値）

**データ取得タイミング**:

- 画面表示時に1回取得
- 食材解放後に再表示する場合は再取得

---

### 結果画面

**表示に必要なデータ**:

- 判定されたレシピ情報
  - name: ラーメン名
  - rating: 評価
  - points: 獲得ポイント
  - comment: コメント
- 初回作成フラグ（図鑑登録通知の表示判定用）

**データ取得タイミング**:

- 調理画面からの遷移時に生成

**データ更新**:

- 画面表示時:
  - 所持ポイントを加算
  - 初回の場合、図鑑に追加
  - 作成回数をカウント
  - LocalStorageに保存

---

### 食材図鑑画面

**表示に必要なデータ**:

- `points`: 所持ポイント
- 全食材データ
- `unlockedIngredients`: 解放済み食材リスト
- 全レシピデータ
- `discoveredRecipes`: 発見済みレシピIDリスト
- `createdCount`: レシピ別作成回数

**状態保持**:

- 選択中のタブ（ラーメン図鑑 / 食材一覧）

**データ取得タイミング**:

- 画面表示時に毎回取得
- 食材解放後に即座に更新
- タブ切り替え時は再取得不要（データは保持）

**データ更新**:

- 解放ボタン押下時（食材一覧タブ）:
  - ポイントを減算
  - 解放済みリストに追加
  - LocalStorageに保存
  - 画面を再描画

## レスポンシブ対応

### モバイル（幅: 〜767px）

- 縦配置レイアウト
- ボタンを大きく（タップしやすく）
- フォントサイズを調整

### タブレット・PC（幅: 768px〜）

- やや余白を持たせたレイアウト
- 最大幅を制限（中央寄せ）

---

## アクセシビリティ考慮事項

### キーボード操作

- Tabキーでフォーカス移動
- Enterキーでボタン実行

### 色覚対応

- 解放済み/未解放をアイコンでも判別可能に（✓/🔒）
- 評価を星の数でも判別可能に

### フォントサイズ

- 最小14px以上
