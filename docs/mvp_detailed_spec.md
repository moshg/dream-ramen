# ラーメンゲーム MVP仕様書

## 目的
最小限の機能で動作するプロトタイプを作成し、ゲームの面白さを検証する。

---

## MVP範囲

### 実装する機能
- ✅ 5スロットのラーメン作成
- ✅ 基本レシピ10種類
- ✅ 食材解放（ポイント消費のみ）
- ✅ 食材図鑑（ラーメン図鑑と食材解放を統合）
- ✅ ゲームデータの保存（LocalStorage）

### 実装しない機能（フェーズ2以降）
- ❌ クリック連打/タイミングゲーム
- ❌ 食材依存関係
- ❌ 実績システム
- ❌ 初回ボーナス

---

## データ構造

### 食材データ
```javascript
{
  id: "shoyu_soup",           // 一意のID
  name: "醤油スープ",          // 表示名
  category: "soup",           // カテゴリ（soup/noodle/ingredient）
  cost: 0,                    // 解放コスト（0は初期所持）
  unlocked: true              // 解放済みフラグ
}
```

### レシピデータ
```javascript
{
  id: "shoyu_ramen",          // 一意のID
  name: "醤油ラーメン",        // 表示名
  ingredients: {              // 必要な食材ID
    soup: "shoyu_soup",
    noodle: "medium_noodle",
    ingredient1: "chashu",
    ingredient2: "negi",
    ingredient3: "menma"
  },
  points: 20,                 // 獲得ポイント
  rating: 4,                  // 評価（1-5）
  comment: "王道の美味しさ！", // コメント
  category: "standard"        // カテゴリ（standard/special/joke）
}
```

### ゲームステート
```javascript
{
  points: 15,                 // 所持ポイント
  unlockedIngredients: [],    // 解放済み食材ID配列
  discoveredRecipes: [],      // 発見済みレシピID配列
  createdCount: {}            // レシピ別作成回数 {recipe_id: count}
}
```

## レシピ判定ロジック

### 判定フロー
1. 選択された食材の組み合わせを取得
2. 登録済みレシピと完全一致をチェック
3. 一致した場合、そのレシピ情報を返す
4. 一致しない場合、デフォルトレシピ（失敗）を返す

### デフォルトレシピ（レシピ未登録の場合）
- 名前: 「イマイチなラーメン」
- ポイント: 3pt
- 評価: ★☆☆☆☆
- コメント: 「うーん...微妙だ...」

### 注意事項
- スロットの順序は問わない（ingredient1-3の順番が違ってもOK）
- 空スロット（なし）も食材として扱う
- 完全一致のみを正解とする（部分一致は不可）

## データ保存仕様

### LocalStorageキー
- `ramenGameState`: ゲームステート全体を保存

### 保存タイミング
- 食材解放時
- レシピ作成時（結果画面表示時）

### 保存データ例
```javascript
{
  points: 45,
  unlockedIngredients: [
    "shoyu_soup", "shio_soup", "medium_noodle", 
    "thin_noodle", "chashu", "negi", "menma", 
    "nori", "miso_soup", "moyashi"
  ],
  discoveredRecipes: [
    "shoyu_ramen", "shio_ramen", "miso_ramen"
  ],
  createdCount: {
    "shoyu_ramen": 3,
    "shio_ramen": 1,
    "miso_ramen": 2
  }
}
```

### データ読み込み
- ページ読み込み時に自動読み込み
- データがない場合は初期状態で開始

### リセット機能
- 開発時のみ実装
- LocalStorageをクリアして初期化

## 既知の制限事項（MVP）

- 初回ボーナスなし（常に同じポイント）
- 食材依存関係なし（すべての食材が最初から一覧に表示）
- クリック連打機能なし（ポイント消費のみ）
- 実績システムなし
- アニメーションなし（最小限のCSS）
- サウンドなし

---

## 次フェーズへの引き継ぎ事項

### データ構造の拡張が必要な項目
- 食材に `requiredIngredient` プロパティ追加（依存関係用）
- レシピに `firstTimeBonus` プロパティ追加（初回ボーナス用）
- ゲームステートに `achievements` 配列追加（実績用）

### 機能追加予定
- クリック連打/タイミングゲーム
- 食材依存関係システム
- 初回ボーナス
- 実績システム
